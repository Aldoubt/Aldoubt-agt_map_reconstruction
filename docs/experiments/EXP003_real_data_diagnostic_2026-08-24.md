## 1. 本轮目标

本轮围绕以下问题展开：

1. `traversability.png` 已经能显示垄的轮廓，是否还值得继续单纯调参。
2. 能否基于最终 PCD 的高度、相对高度和可通行证据，处理枝叶遮挡及传感器噪声，得到初步可用的全局导航地图。
3. 手持三维扫描仪数据是否适合逐帧 raycasting 与概率融合；与直接处理高质量最终 PCD 相比，哪条路线性价比更高。
4. EXP003 默认参数运行后代价地图几乎全部不可通行，究竟是地面模型失效，还是障碍膨胀等下游步骤造成的。

本轮形成的路线判断是：

- 当前以最终 PCD 为基准，优先把 PCD 路线的诊断链、证据层和地图评价做扎实。
- rosbag/逐帧 raycasting 与概率融合值得测试，但暂不作为当前基准；待 PCD 路线的上限和失败模式明确后再进入 EXP004。
- 不再盲目围绕单一阈值调参，而是把问题拆成地面模型、单元格证据、障碍净化、膨胀和地图评价五个环节。

## 2. 对话与实验时间线

### 2.1 从 EXP002 转向 EXP003

EXP002 的三组走廊提取结果为：

| 方案 | corridor_cells | 观察 |
|---|---:|---|
| EXP002-A | 396,064 | 明显过分割，大片区域被认作走廊 |
| EXP002-B | 951 | 严重塌缩，只保留极少局部区域 |
| EXP002-C | 26,748 | 能发现部分局部垄间结构，但全局连续性不足 |

由此得到的判断是：二值地面分割或一次性形态学走廊提取不足以直接形成导航地图。`traversability.png` 中已有清晰的行向结构，因此应保留连续高度信息和多类证据，而不是过早二值化。

### 2.2 EXP003 设计方向

EXP003 采用四态证据地图：

- `unknown`：缺少可靠观测，不能当作自由空间。
- `free`：有足够的低位/地面证据支持可通行。
- `occupied`：存在高于局部地面的障碍证据。
- `interpolated`：仅在方向、距离和邻域一致性约束下补齐的小范围缺口。

生成链路可概括为：

1. 将 PCD 投影到二维网格。
2. 每格提取低高度或低分位高度。
3. 估计局部地面曲面。
4. 计算 `clearance = low_height - ground_surface`。
5. 结合点数、净空和局部连续性生成证据层。
6. 将证据映射为代价地图。
7. 对障碍应用机器人安全膨胀。

### 2.3 默认膨胀实测

首次正式运行完成，但 `costmap.png` 几乎全部呈高代价。与此同时，测试收集阶段出现：

```text
ImportError: numpy.core.multiarray failed to import
```

这不是 EXP003 算法本身的运行失败，而是 Python 环境混用了多套包：用户目录中的 pytest、ROS Humble 的 `launch_testing`、系统 Matplotlib，以及 ABI 不匹配的 NumPy。

建议使用完全隔离的虚拟环境，并禁用 pytest 插件自动加载：

```bash
deactivate 2>/dev/null || true
python3 -m venv --clear .venv
source .venv/bin/activate
unset PYTHONPATH
export PYTHONNOUSERSITE=1
python -m pip install --upgrade pip setuptools wheel
python -m pip install -e .
python -m pip install pytest
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONNOUSERSITE=1 \
  python -m pytest tests -q
```

还应确认 `.venv/pyvenv.cfg` 中：

```text
include-system-site-packages = false
```

## 4. 图像层诊断

### 4.1 `low_height.png`

- 垄向纹理明显，说明二维投影仍保留了农田结构。
- 中下部高植被与噪声更加密集，空间质量不均匀。
- 极端高度超过 20 m，压缩了色阶；诊断图应改用 P1–P99 或 P2–P98 分位显示。

### 4.2 `ground_surface.png`

- 中下部地面曲面出现明显的垄向条带和局部抬升。
- 地面模型可能把部分作物或垄体当作地面，导致基准面随障碍起伏。
- 白色缺口表示局部曲面缺失或无有效估计，会进一步造成 clearance 和证据的不连续。

### 4.3 `clearance.png`

- 净空约从 `-2 m` 延伸到 `>10 m`，存在大量物理上不合理的负净空。
- 负净空表明局部低高度低于估计地面，通常意味着地面面被抬高、跨行平滑、局部外推错误或点云离群。
- 因此当前不能只调 free/occupied 阈值；必须先统计和约束负净空。

### 4.4 `evidence.png`

- 原始证据中可见大量平行、方向一致的自由带，这是本轮最重要的积极结果。
- 中下部 occupied 证据呈密集碎片状，符合枝叶遮挡、传感器噪声和地面误差共同造成的表现。
- `interpolated = 7`，说明当前插值规则过于保守或触发条件不合适，尚未解决遮挡断裂。

### 4.5 `costmap.png`

- 默认膨胀后大部分区域变为高代价，说明障碍碎片在窄行间发生大面积叠加。
- 无膨胀后平行自由带重新显现，证明塌缩主要发生在证据到代价地图的后处理阶段。
- 当前连续色图还把 `occupied=254` 与 `unknown=255` 都显示成相近黄色，容易误读；后续必须使用离散颜色。

## 5. 本轮结论

### 5.1 已经验证的部分

1. 最终 PCD 中包含足以恢复垄间方向和自由带的结构信息。
2. EXP003 的四态表达比 EXP001/EXP002 的二值结果更适合后续导航，因为它没有把未知区域直接当作自由空间。
3. 当前失败不是“完全没有识别出垄间地面”，而是地面曲面误差、碎片障碍和统一膨胀共同造成地图塌缩。
4. 关闭膨胀是有效的诊断手段，但不是可部署方案。
5. 当前不宜继续进行无目标的单参数调优，应先增加可解释统计和参数扫描工具。

### 5.2 尚未解决的问题

1. 地面曲面在植被密集区可能被抬高，并出现沿行传播的错误。
2. clearance 存在显著负值，缺少物理一致性约束。
3. 单格 occupied 判定对枝叶和离群点过敏，缺少高度分布与空间连续性判据。
4. 插值几乎未生效，遮挡导致的短缺口没有得到有效修复。
5. 固定圆形膨胀没有结合机器人 footprint、定位误差和垄间方向。
6. 缺少人工标注 ROI 和定量评价，目前仍主要依赖整图肉眼判断。

## 7. 下一轮测试落地思路

### 阶段 A：只基于现有 `.npy` 做诊断，不重复读取 8,591 万点

优先新增一个诊断/扫描脚本，读取已经生成的 `low_height.npy`、`ground_surface.npy`、`clearance.npy`、`evidence.npy` 和 `costmap.npy`。

输出内容：

1. 离散证据图：unknown 黑、free 白或蓝、occupied 红、interpolated 橙。
2. 离散代价图：free 白、interpolated 蓝、occupied 红、unknown 黑。
3. `low_height`、`ground_surface` 和 `clearance` 的 P1/P5/P50/P95/P99。
4. `clearance < -0.05 m` 的格数、比例和空间分布。
5. 膨胀半径扫描：`0, 0.05, 0.10, 0.15, 0.20, 0.25, 0.40 m`。
6. 每个半径下的剩余自由格、最大自由连通域、沿行连通率、横向泄漏率和自由带宽度。

这一阶段成本低，且能直接回答“是半径不合适，还是障碍证据本身过密”。

### 阶段 B：增强单元格证据

每格不再只保留一个低高度值，而是增加：

- `Q10/Q50/Q90`
- 最大值与高度跨度
- 地面附近点数
- 机器人碰撞高度带内点数
- 点密度和有效观测次数

建议的初始物理约束：

- `clearance < -0.05 m`：先标记为 unknown/ground-model-invalid，而不是 free。
- `-0.05 m <= clearance <= 0.15 m`：作为自由候选。
- `clearance > 0.15 m`：结合碰撞高度带点数和密度判定 occupied，避免单个枝叶点直接形成障碍。

具体阈值必须通过 ROI 标注评估，不应直接视为最终参数。

### 阶段 C：障碍去噪但保留真实细杆

需要同时避免两类错误：枝叶碎点被当成墙，以及温室立柱被滤掉。

建议组合：

1. 最小点数/最小重复观测门槛。
2. 垂直高度跨度或碰撞高度带占比。
3. 与垄方向的连续性和横向宽度。
4. 小连通域过滤，但对高而窄的柱状目标设置保留规则。
5. 对自由带只允许沿垄方向修复短缺口，禁止跨垄连接。

### 阶段 D：地面算法对照实验

在相同 PCD、相同网格和相同 ROI 上比较：

1. 当前局部曲面方法。
2. 正式 PMF（Progressive Morphological Filter）。
3. GroundGrid/分块局部地面模型。
4. Patchwork++ 作为补充；它更适合逐帧或有传感器位姿的数据，最终 PCD 上可测但不一定发挥全部优势。

比较指标不只看地面点比例，还应看：

- 负净空比例。
- 清晰垄间的 free recall。
- 垄体和立柱的 occupied precision。
- 遮挡缺口的 unknown 保守性。
- 膨胀后的走廊保留率。

### 阶段 E：建立小规模人工标注 ROI

至少选取以下区域：

1. 清晰垄间地面。
2. 枝叶遮挡区。
3. 下部高密植被区。
4. 垄边界。
5. 温室立柱或框架。
6. 点云空洞/未知区。

每类先标少量矩形 ROI 即可。由此计算 precision、recall、unknown 误填率和走廊连续性，避免整图凭肉眼反复调参。

## 8. 建议的验收条件

初步可用的全局导航地图至少应满足：

1. 未知区不自动转为 free。
2. 垄体、立柱和稳定障碍能够被阻挡。
3. 使用合理机器人 footprint 和安全余量后，主要垄间仍保持连续。
4. 可用走廊宽度大于机器人宽度加双侧安全余量。
5. 沿垄方向可修复短遮挡，不能跨垄错误连通。
6. 负净空比例下降到可解释的小范围。
7. 同一输入和配置可复现相同结果，并在 metadata 中记录完整输入哈希、参数和 git 状态。

## 9. rosbag / 手持扫描逐帧融合路线

手持扫描仪数据可以做逐帧 raycasting 和概率融合，前提是能够获得：

- 原始逐帧点云或深度数据。
- 每帧可靠的传感器位姿。
- 正确的时间同步和坐标变换。

与最终 PCD 相比，逐帧方法可以利用“射线经过区域为空闲、末端命中为占用”的观测模型，也能通过多帧概率累积抑制偶发枝叶和噪声，理论可靠性更高。但其代价是数据接口、位姿误差、时间同步和计算复杂度都更高。

因此当前决策是：

- 继续把 PCD 路线作为 EXP003 基准，因为它已有较好点云，开发和验证成本最低。
- 将逐帧 raycasting + 概率融合记录为 EXP004 候选方案。
- 只有当 EXP003 的障碍去噪、地面模型和 footprint 膨胀完成后仍无法满足验收条件，或需要进一步提升遮挡区可信度时，再正式投入 EXP004。

## 11. 一句话总结

EXP003 已经从最终 PCD 中恢复出可信的垄向自由结构；当前“地图几乎不可用”主要是局部地面误差与碎片障碍在统一安全膨胀下被放大，而不是点云本身不含走廊信息。下一轮应先建立离散可视化、负净空统计、膨胀扫描和 ROI 指标，再增强单元格高度分布与方向约束，最后决定是否需要升级到逐帧概率融合。
